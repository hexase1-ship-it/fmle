#FMAX 파일 검증 오류가 뜰 때

설치에 필요한 파일이 빠지거나 손상됐거나, 서로 다른 판의 파일이 섞였을 수 있습니다. getfmax.com의 FMAX-setup.exe로 다시 설치합니다. fmax.exe 하나만 옮기지 말고 설치 폴더의 파일을 함께 둡니다.

실행 중 안내가 떴다면 새 편집을 멈추고 FMAX의 종료 안내를 따릅니다. 다시 설치할 때 "애플리케이션 데이터 삭제하기" 는 체크하지 않습니다. 설정과 목록을 남겨 두기 위해서입니다.

창 오른쪽 위 연결 표시를 누르면 지금 상태와 할 일이 나옵니다.

연결 상태 창의 다시 확인(연결되지 않았을 때)은 게임을 다시 찾고, 게임에서 다시 읽기(연결되었을 때)는 게임의 목록을 다시 읽습니다.

#버전 다름이 뜰 때

FMAX는 FM27 27.0.1+2503222 원본과, 그 원본에 DoF 패처를 적용한 파일에서만 게임을 읽고 씁니다. 이때 확인하는 파일은 게임 폴더의 game_plugin.dll입니다. 이 파일이 다르면 연결 표시에 버전 다름이, 왼쪽에 다른 게임 버전 카드가 뜨고 FMAX는 게임을 읽지도 쓰지도 않습니다.

까닭은 셋 중 하나입니다.

  1. 게임이 켜진 채 game_plugin.dll을 바꿨습니다. 게임을 다시 시작합니다.
  2. 다른 패치나 스킨 부가 기능이 game_plugin.dll을 바꿨습니다. 연결 상태 창에 다른 모드가 고친 게임 파일입니다가 뜨면 호환 모드 켜기를 누르거나 설정에서 호환 모드를 켭니다. 그 패치와 겹치는 FMAX 기능만 꺼지고 나머지는 그대로 씁니다. 호환 모드로도 연결되지 않으면 그 패치를 빼서 파일을 원본으로 돌립니다. 패치를 되돌리는 방법을 모르면 Steam 라이브러리에서 FM27을 오른쪽 클릭 → 속성 → 설치된 파일 → 게임 파일 무결성 확인을 누르면 게임 파일이 원본으로 돌아옵니다. 그다음 게임을 다시 켭니다.
  3. FM27 자체가 다른 판으로 업데이트되었습니다. 이때는 새 게임 판에 맞춘 FMAX가 나와야 연결됩니다.
주의

무결성 확인은 game_plugin.dll뿐 아니라 다른 패치가 바꾼 게임 설치 파일도 모두 원본으로 돌립니다. DoF 패처를 적용해 두었다면 그것도 풀립니다. 문서 폴더의 스킨처럼 게임 설치 폴더 밖에 있는 것은 건드리지 않습니다.

#시작 화면에서 멈출 때

FMAX를 켤 때 시작 화면이 끝나지 않으면 까닭과 단추가 나옵니다.

안내뜻
게임 구조 정보를 불러오지 못했습니다FMAX가 자기 자료를 열지 못했습니다. FMAX를 다시 켭니다.
FMAX를 준비하다가 멈췄습니다20초가 지나도 준비나 게임 확인이 끝나지 않았습니다. FMAX를 다시 켭니다.
그 밖의 안내위 연결 표시 표와 같은 뜻입니다.
  • 다시 시도: FMAX 준비에서 멈췄으면 FMAX 화면을 처음부터 다시 열고, 게임 찾기·읽기에서 멈췄으면 게임을 다시 찾습니다.
  • 기록 저장 · 기록 복사: 개발자에게 보낼 기록입니다. 아래 개발자 기록 보내기를 봅니다.
  • 그냥 들어가기: 시작 화면을 닫고 목록 화면으로 들어갑니다.

계속 같은 곳에서 멈추면 기록을 저장해 개발자에게 보내 주세요.

#전술 파일이 목록에 없을 때

전술 아레나, 전술 화면, 편의 기능의 AI 감독 전술 고정은 게임의 전술 폴더에 있는 전술 파일(.fmf)을 보여 줍니다. 게임의 전술 화면에서 저장한 전술이 목록에 없다면, 게임이 파일을 다른 곳에 저장하고 있을 수 있습니다(게임 설정에서 저장 폴더를 옮겼거나, 문서 폴더가 다른 드라이브나 OneDrive에 있는 경우).

전술을 고르는 자리의 전술 폴더 줄에서 FMAX가 지금 읽는 폴더와 그 폴더를 어떻게 찾았는지 볼 수 있습니다.

가져온 파일을 목록에서 빼기전술 폴더 줄의 그 파일 옆 빼기를 누릅니다. 원래 파일은 지워지지 않습니다.

'쓰다가 실패했습니다'가 뜬 뒤에는 FM에서 게임을 저장하기 전에 값을 꼭 확인합니다. 일부만 바뀐 값이 그대로 세이브에 남을 수 있습니다.

저장 단추에 연결되면 적용이 보이고 눌리지 않으면, 탭의 값이 지금 켜져 있는 게임에서 읽은 값이 아닙니다. 연결된 뒤 탭의 게임에서 다시 읽기(둥근 화살표)를 누릅니다.

#바꾼 값이 원래대로 돌아갈 때

아래를 차례로 확인합니다.

  1. 저장을 눌렀나요? 탭 아래쪽에 '바꾼 값' 막대가 남아 있으면 아직 게임에 쓰지 않은 것입니다. 처음 시작하기를 봅니다.
  2. FM에서 게임을 저장했나요? FMAX가 쓴 값은 실행 중인 게임에 들어갑니다. FM에서 저장하지 않고 세이브를 다시 불러오면 사라집니다.
  3. 게임이 다시 바꾼 값인가요? 저장으로 쓴 값도 게임은 평소처럼 바꿉니다. 능력치는 훈련과 성장으로, 몸값은 게임이 다시 계산하는 날에 바뀝니다. 값을 붙잡아 두려면 고정을 씁니다. 고정은 FMAX가 켜져 있는 동안 게임이 값을 바꾸면 다시 써 넣습니다.
  4. 편의 기능이나 고정이 꺼졌나요? 편의 기능과 고정은 FMAX가 켜져 있는 동안만 작동합니다. FMAX를 다시 켰을 때 설정의 FMAX를 다시 켜면 지난번 상태 그대로가 꺼져 있으면 멈춘 채로 시작합니다.

포지션 숙련도를 고쳐도 날짜가 지나면 돌아간다는 제보가 있습니다. 원인은 아직 확인하지 않았습니다.

#흰 화면이나 'out of memory'가 뜰 때

오래 켜 두면 FMAX 창이 하얗게 되거나 'out of memory'가 뜨며 새로 고침을 요구한다는 제보가 있었습니다.

  • 26.1107.1205에서 FMAX 화면이 차지하는 양을 약 4분의 1로 줄였고, 26.1107.1326에서 닫은 탭의 자료를 정리하는 등 더 줄였습니다.
  • 원인을 모두 확인한 것은 아닙니다.

할 일은 이렇습니다.

  1. 왼쪽 도구 → 업데이트 노트에서 지금 쓰는 판을 보고, 이보다 낮으면 최신 판으로 업데이트합니다.
  2. 이미 뜬 창은 FMAX를 닫았다가 다시 켭니다.
  3. 최신 판에서도 계속되면 개발자 기록을 저장하고, 어느 화면에서 무엇을 하다가 떴는지 함께 보냅니다.

#업데이트나 설치가 안 될 때

  • 업데이트 알림의 설치를 눌렀는데 '새 판을 설치하지 못했습니다'가 뜨면, 함께 뜬 까닭별 할 일은 업데이트가 안 될 때에 있습니다.
  • 그 까닭이 manifest_policy이면 게임 판이 바뀐 새 판이라 앱 안 업데이트로 받을 수 없는 경우입니다. getfmax.com의 FMAX-setup.exe로 설치합니다. 설정과 목록은 그대로 이어집니다.
  • 설치나 제거 중 'FMAX가 아직 닫히지 않았어요'가 뜨면 설치나 제거가 멈출 때를 봅니다.
  • 설치 파일을 실행할 때 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다. FMAX에 유료 코드 서명 인증서가 없어서 뜨는 창입니다.

#FMAX가 닫히지 않을 때

창의 닫기 단추를 누르면 FMAX는 먼저 게임에 걸어 둔 편의 기능과 규칙을 원래대로 돌린 뒤 닫힙니다. 돌리지 못하면 일부러 닫히지 않고 '게임 규칙을 원래대로 돌리지 못해서 FMAX를 열어 두었습니다' 와 까닭을 띄웁니다. 까닭을 확인하고 다시 닫아 봅니다. 계속되면 개발자 기록을 보냅니다.

에리 설정의 FMAX 창을 닫아도 남기를 켜 두었다면, 창을 닫아도 FMAX는 알림 영역에 남습니다. 에리를 오른쪽 클릭해 끝냅니다.

#개발자 기록 보내기

FMAX는 문제가 생겼을 때 개발자에게 보낼 기록을 만들어 둡니다. 기록에는 FMAX·Windows·게임 파일의 판, 어디서 멈췄고 왜 멈췄는지, 단계마다 걸린 시간이 들어갑니다. 폴더 이름과 세이브 이름은 빠집니다. 최근 다섯 번 실행한 것까지 남아 있어서, 끝까지 가지 못한 실행도 다음에 켰을 때 보낼 수 있습니다.

  1. 오른쪽 위 연결 표시를 눌러 연결 상태 창을 엽니다. 시작 화면에서 멈췄다면 그 화면의 단추를 씁니다.
  2. 창 아래쪽 개발자 기록에서 고릅니다.
    • 저장: 다운로드 폴더에 FMAX-log로 시작하는 글 파일을 만듭니다.
    • 복사: 기록을 복사합니다. 카톡이나 디스코드에 붙여 넣어 보냅니다.
  3. 어떤 화면에서 무엇을 하다가 생겼는지 함께 적어 보냅니다.
