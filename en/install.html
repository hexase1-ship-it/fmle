Getting started

Installing, updating and uninstalling

Install FMAX without administrator rights using a single installer, update from inside the app after confirming, and see what to keep in mind when uninstalling.

#What you need

  • Windows 10 or 11 (64-bit)
  • FM27 version 27.0.1+2503222. FMAX won't connect if your game version is different.

FMAX never modifies your game files on disk. It reads and writes values in the running game while FMAX is open.

#Downloading the installer

The only file you need to download is FMAX-setup.exe from getfmax.com. It's a lightweight installer: every time you run it, it downloads the newest version, verifies its signature, and opens the setup wizard. Even if you re-run an older copy of FMAX-setup.exe months later, it will still fetch and install whatever version is latest then. Files downloaded from other sources won't pass FMAX's signature check.

#Installing

  1. Run the downloaded FMAX-setup.exe.
  2. If the blue "Windows protected your PC" screen appears, click More info and then Run anyway.
  3. A small window appears briefly while the latest version downloads, followed by the setup wizard. Click Next → Install → Finish. Leave Create Desktop Shortcut checked on the final screen if you'd also like FMAX on your desktop.

The "Windows protected your PC" warning appears because FMAX does not use a paid code-signing certificate. As long as you downloaded the installer from getfmax.com, it is safe to run. Your browser may show a similar prompt during download.

Here is what installation sets up:

  • Installs only to your own Windows user account (%LOCALAPPDATA%\FMAX). Administrator rights are not required.
  • Adds FMAX to the Start menu.
  • Registers FMAX under Windows Settings → Apps → Installed apps, which is where you uninstall it.

Once installed, head over to Getting started.

Keep all files in the installation folder together. Do not move fmax.exe on its own to another folder or mix files from different versions. If required files are missing or damaged, FMAX stops on startup and lets you know. Reinstall using the installer from the Releases page above, leaving "Delete application data" unchecked so your settings and lists stay intact.

#Updating to a new version

A few seconds after opening, an installed copy of FMAX checks once for updates. When a new version is out, a "New version … is available · Current version is …" banner appears for 30 seconds with an Install button.

  1. Click Install on the notification.
  2. A confirmation dialog asks "Update to version …?" Click Install to go ahead, or Later to skip for now.
  3. 'Downloading update' appears along with download progress (%).
  4. 'Preparing installation · FMAX will close and restart shortly' appears, and FMAX closes.
  5. Once installation finishes, the updated FMAX launches automatically.

During an update, FMAX takes care of the following:

  • It installs the update only after verifying its digital signature to confirm the file genuinely came from FMAX. If the signature doesn't match, installation is aborted.
  • Before closing, FMAX temporarily lifts any Live tweaks and game rules it had active. When the new version opens, they turn back on according to Restore previous state on launch in Settings. If that setting is turned off, everything starts paused so you can re-enable them on each screen.
  • If you were using Keep men’s team eligibility, FMAX may ask you to reload your save after restarting.
  • Everything FMAX remembers—Settings, presets, Shortlist, and your Live tweaks and Locks lists—carries over untouched.

If you missed the banner or clicked Later, FMAX will notify you again the next time you open it.

#Updating manually

Downloading and running a fresh installer from the Releases page updates FMAX in the exact same way, keeping all your settings and lists.

Careful

If an uninstall screen pops up during setup, do not check "Delete application data". Checking it wipes all settings and lists FMAX has saved.

#Checking your current version

Open Update notes under Tools on the left to see your installed version number, marked with a 'Current' badge in the release list. You can also see what changed in each release there (Settings and Update notes).

#Upgrading from FMLE to FMAX

FMLE was FMAX's earlier name. Updating from FMLE to an FMAX release makes these changes:

  • FMAX installs into a new folder (%LOCALAPPDATA%\FMAX).
  • FMLE shortcuts on your desktop and Start menu are replaced with FMAX shortcuts. Shortcuts pointing to an FMLE copy in another location are left alone.
  • Program files in the old folder (%LOCALAPPDATA%\FMLE) and the FMLE uninstall entry are removed. If you placed any personal files in that folder, the folder and your files are kept.
  • Your settings, lists, Live tweaks, Locks and records carry over automatically.

#Uninstalling

  1. Open Windows Settings → Apps → Installed apps.
  2. Open the menu next to FMAX and click Uninstall.

If FMAX is running, the uninstaller closes it first—restoring any active Live tweaks and game rules beforehand just like clicking the window's close button.

The "Delete application data" checkbox on the uninstaller works like this:

CheckedUnchecked
Everything FMAX saved on this PC (Settings, presets, Saved filters, Shortlist, favourites, per-save Live tweaks and Locks, etc.) is deleted as well.Your data stays on this PC and comes right back if you reinstall later.
Careful

FMAX data removed with "Delete application data" cannot be recovered. Leave it unchecked if you might reinstall FMAX later.

Uninstalling FMAX does not change values already written to the game or saves you've already saved in FM.

#When installation or uninstallation stops

Before replacing or removing files, the installer, updater or uninstaller asks any running copy of FMAX to close. If FMAX hasn't closed within 60 seconds, a message appears—"FMAX hasn't closed yet. Check the message in the FMAX window, close FMAX, and try again."—and setup stops without altering your existing installation.

FMAX deliberately stays open if it can't restore changes it made to the game's rules. When that happens, the FMAX window shows 'FMAX stayed open because game rules couldn't be restored'. Follow the prompt in FMAX, close it, and run setup again.

If Eri is turned on with Stay when FMAX closes enabled in Eri's settings, closing the main window leaves FMAX running in the system tray. Right-click Eri to quit FMAX completely, then try again.

For anything else, see Troubleshooting.
