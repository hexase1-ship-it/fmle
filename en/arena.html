Tactic Arena

Have the game play out hundreds of matches with your tactic files and rank them by points to see which ones come out on top. It works in three steps: create a test sheet, run your tactics, and read the rankings.

#What is the Tactic Arena?

Click Tactic Arena under Tools in the left sidebar to open it. It has the game play hundreds of matches on your behalf using your tactic files, then ranks your tactics based on the results.

There are five tabs across the top.

TabWhat it does
TableView the rankings so far for each test sheet
Run testsPick the tactic files you want to compare and run matches
Auto searchHave FMAX tweak instructions one at a time on a single tactic to find a stronger setup
Test sheetChoose the test team and its opponents
Official testA standardized test every user runs under the same conditions, covered separately in Official test and the Tactic Lab

How to use in the top right walks you through the three steps from setup to reading the rankings.

Careful

You can't play the game while a test is running—leave the game paused and don't advance the date. In Live tweaks, Lock AI manager tactics and 100% tactical effectiveness are paused while testing runs and turned back on once it finishes.

#Getting started: three steps

  1. Create a test sheet. Pick a test team and its opponents. Once you make one, you can keep reusing it.
  2. Run your tactics. Pick the tactic files you want to compare and click Start. The game plays out the matches for you.
  3. Read the rankings. Higher expected points mean a stronger tactic. If two tactics' ranges overlap, it's still too close to call.

FMAX reads tactic files from your game's tactics folder (Sports Interactive\Football Manager 27\tactics inside your Documents folder). Any tactic you save on the tactics screen in FM shows up here.

Every tactic picker includes a Tactics folder line showing which folder FMAX is currently reading. If your tactics aren't listed, click Choose folder there to point FMAX to the folder where your tactics live, or drag and drop a tactic file (.fmf) straight into the FMAX window. For details, see 'Tactic files don't show up in the list' under Troubleshooting.

#Test sheets

A test sheet sets identical match conditions for every candidate you compare. It bundles together one AI team to run the tactic, a set of AI opponent teams, squad and familiarity rules, and baseline set pieces. Set one up once and reuse it anytime—all results run on the same test sheet accumulate in a single rankings table.

FieldMeaning
Test teamNot the club you manage yourself. Pick the senior squad of any AI-managed club in your current save (clubs managed by a human can't be chosen). FMAX hands the tactic file under test to this club's AI manager and plays out the matches
OpponentsPick between 1 and 40 AI-managed clubs. Each round plays every chosen opponent once at home and once away. You can assign a specific tactic and set piece file to each opponent (if you assign a tactic, you must also assign set pieces), and that opponent will always play with those files. If left blank, it isn't random—that club's AI manager picks tactics and set pieces just as they normally do in the game. Opponents' tactics and set pieces never change, no matter what you compare in Run tests
Use equal squadsWhen on, both the test team and all opponents use identical test squads so player ability doesn't skew the comparison (Role squad: 26 standard players tailored to each position / Uniform squad: every outfield player has the exact same attributes). When off, each team plays with its real players
Max tactical familiarityWhen on, both sides play at full tactical familiarity so a new tactic isn't penalized for being unfamiliar. When off, each team plays at its actual familiarity
Baseline set piecesSet pieces locked onto the 'Test team' alone when comparing tactics. Opponents don't use these—they use whatever you assigned per opponent above (or their AI manager's choice). You must set baseline set pieces to use Tactic comparison and Auto search
NameLeave blank to name it automatically after the team and number of opponents

There are two kinds of test sheets:

  • Standard test: Every opponent's tactic and set pieces are locked to files, and both Use equal squads and Max tactical familiarity are turned on. Because the test is identical regardless of who runs it or in which save, you can share and merge rankings files with other FMAX users on the same game version.
  • My save test: Any test sheet missing at least one of those three conditions (AI managers pick opponent tactics, teams use real players, or teams use actual familiarity). Results can only be compared within your current save and can't be merged with other users' rankings.

At the bottom of the test sheet builder, FMAX shows which type your sheet qualifies as and what else you need to fill in to make it a Standard test.

#Using the same conditions as the Official test

In Use Official test conditions on the right side of the Test sheet tab, click Create to generate a personal test sheet using the exact same club, opponents, opponent tactics, squad rules, familiarity, and baseline set pieces as the Official test. Its name starts with 'Official conditions practice'. You can freely run Tactic comparison, Set piece comparison, and Auto search on it.

  • Results stay in your own rankings and aren't posted to the Tactic Lab leaderboard. To submit an official score, test in the Official test tab.
  • If an official club isn't available in your save, FMAX substitutes a replacement club just like Official test does.
  • If the Tactic Lab later updates its official test sheet, your sheet gets marked 'Official test sheet changed'. Click Create again to build one with the current conditions.

Test sheets marked 'Legacy' are records from an older version of FMAX. You can view them, but you can't run more matches on them—create a new test sheet to test again.

#Run tests

  1. Choose a test sheet. Pick which test sheet to run on.
  2. What to compare. Whatever you pick here, opponents always keep the tactics and set pieces defined on the test sheet—only the 'Test team' changes.
    • Tactic comparison: Swaps only the tactic on the 'Test team' one candidate at a time against the same opponents. The 'Test team' always uses the test sheet's single Baseline set pieces file (not applied to opponents). Requires a test sheet with baseline set pieces, and is the most common way to test.
    • Set piece comparison: Swaps only the set pieces on the 'Test team' one candidate at a time. For its tactic, the 'Test team' uses the 'Fixed tactic' (1 to 4 files) you choose. If you pick two or more fixed tactics, each set piece candidate is tested with every one of them and the rankings show the average.
    • Combination test: Pairs a tactic file with a set piece file on the 'Test team' and tests each pair together, without separating how much of the score came from the tactic versus the set pieces.
  3. Tactics to test. Pick the files to compare (tactic files for Tactic comparison, set piece files for Set piece comparison, or tactic + set piece pairs for Combination test). You can queue up to 16 candidates at once, and each candidate becomes one row in the rankings. Testing a candidate you've already run adds the new matches onto its existing record.
  4. How many matches. This is the match count per candidate, not the combined total (Quick 200, Standard 1,000, Precise 2,000, or type a custom number). Playing every opponent on the test sheet once at home and once away is one 'round', and because matches are completed in full rounds, your chosen match count is rounded up to a multiple of one round (opponents × 2). For example, with 10 opponents, one round is 20 matches; if you pick 200 matches, each candidate plays ten 20-match rounds (600 matches total across 3 candidates). A candidate must finish at least one full round (home and away against every opponent) to appear in the rankings. Running more matches narrows the margin of luck (Range (±)) and makes the rankings firmer, at the cost of taking longer.
  5. Click Start. On the right, FMAX shows the estimated time and total match count beforehand.

We recommend leaving Save time turned on:

  • Show early rankings first: Runs roughly 200 matches for every candidate first so they appear in the rankings early, then completes the remaining matches.
  • Stop unlikely candidates early: Skips the remaining matches for candidates with almost no chance of making the top 10.
  • Stop when accurate enough: Skips the remaining matches for candidates whose Range (±) has already narrowed to your chosen threshold.

While matches are running, you can't use the game, though the in-game date never advances and nothing is saved to your save file. Matches played, W-D-L, goals, and expected points update live for each candidate. Click Stop to finish after the match currently in progress—everything recorded up to that point stays in the rankings.

#Read the rankings

Pick a test sheet at the top of the Table tab to see its rankings. You can switch between three views: Tactic rankings, Set piece rankings, and Combinations.

ColumnMeaning
Expected pointsPoints expected over a 38-match season with this tactic. Higher is better
Range (±)How much the result can swing due to luck. Narrows as you run more matches. If two tactics' ranges overlap, you can't tell which one is stronger yet
Rank rangePlausible range of true ranks once luck is factored in. A wide range means you need more matches to settle the order
Chance of 1stProbability that this candidate is genuinely #1 based on the results so far
GD, Scoring, Goals concededPer-season figures scaled to a 38-match season
Home, AwayPoints scaled to 19 home matches and 19 away matches respectively
xG diffFull-season expected goals for minus expected goals against. Higher means stronger underlying play
MatchesMatches played and W-D-L record

Above the table, a single summary line tells you who sits #1 right now—and if it isn't clear-cut yet, why (which candidates have overlapping ranges). Hover over any unfamiliar term to see a tooltip explanation.

#Run more and Confirmation test

Select candidates in the rankings (Select contenders for 1st selects every candidate still in contention for #1 at once) to bring up the bottom action bar:

  • Run more: Sends the selected candidates to the list in the Run tests tab. Running more matches narrows their range.
  • Confirmation test: Re-tests only the selected candidates in a fresh set of matches. When you pick the #1 tactic out of many candidates, good luck may have boosted its score, so this calculates a fresh score from brand-new matches alone. Once finished, it's listed separately in the rankings under 'Confirm'.
  • Export selected: Saves only the selected candidates' records and tactic files to a file.

#Viewing a single tactic's record

Click a tactic's name in the rankings to open its detailed record. You'll find its expected points and range, W-D-L, home and away splits, plus sections for top scorers and assisters, pass map and heatmap, goal times, scorelines, set pieces, and results by opponent.

Buttons across the top: Back to rankings, View tactic details (positions, roles, and instructions in that tactic), Add to game (copies the tactic file into your game's tactics folder), Rename, and Remove.

#Exporting and importing

  • Export: Saves these rankings along with the tactic files into a single file that other FMAX users can import and merge into their own rankings.
  • Import rankings: Merges a rankings file exported by another user into yours. Only Standard tests run on the same game version and match engine can be merged.
  • Save as image: Saves the rankings table as a PNG image.
  • Ask Eri: Opens Eri with a question about these rankings filled in for you.

#Auto search

Give FMAX a single tactic and it will tweak instructions one at a time to search for a stronger combination automatically, keeping your formation as is. Only works on test sheets that have baseline set pieces.

  1. Which tactic to start from. Pick a tactic file.
  2. What to try changing. Toggle any of Mentality, Out of Possession instructions, In Possession instructions, and Roles. Turning on more options creates more candidates to test and takes longer—Roles in particular expands the pool dramatically and requires plenty of time.
  3. How long to search. Pick anywhere from 30 minutes to 8 hours. Shorter searches catch only big gains; longer searches can tease apart smaller improvements too.
  4. Click Start search.

FMAX starts broad with small match samples across many candidates, keeps the promising ones, and invests more matches into them. At the end, it pits the Original tactic against the Best candidate in fresh matches for a Confirmation test.

Completed runs stay under Past searches, where you can inspect the Best candidate, Confirmation test diff, Matches run, and the step-by-step search history. Add best candidate to game copies the winning tactic file into your game's tactics folder.

Good to know

A winner picked out of many candidates can look better than it really is thanks to luck. Base your verdict on the Confirmation test diff from the fresh head-to-head matches—if its range crosses 0, you can't tell which tactic is better yet.

#Sending tactics over from the Tactics screen

Variant tactics created with 'See which works best in the Tactic Arena' on the Tactics screen appear directly in the candidate list on the Run tests tab.
