Troubleshooting

What to do when FMAX won't connect, shows Version mismatch, fails to save, reverts your edits, or turns into a white screen—organized by the exact message FMAX shows.

#FMAX file verification error

Required installation files may be missing or corrupted, or files from different versions may have been mixed together. Reinstall using FMAX-setup.exe from getfmax.com. Keep all files in the installation folder together rather than moving fmax.exe on its own.

If this message appears while FMAX is running, stop making new edits and follow FMAX's prompts to close the app. When reinstalling, do not check "Delete application data" so your settings and lists stay intact.

#FMAX won't connect to the game

Click the connection indicator in the top-right corner of the window to see the current status and what to do next.

If it stays like this after the main menu is up, check whether only the game was run as administrator; if so, run FMAX as administrator too. Up to 26.1113.723 this case also showed as 'starting'.
Waiting for saveNo save loaded yetLoad a save and FMAX will read it automatically.
Version mismatchUnsupported game versionSee When Version mismatch appears below.
No accessCan’t open the gameIf you ran the game as administrator, run FMAX as administrator too (right-click the FMAX icon → Run as administrator).

In the Connection status popover, Check again (shown when disconnected) searches for the game again, and Reload from game (shown when connected) refreshes the lists from the game.

#When Version mismatch appears

FMAX only reads and writes to the original FM27 27.0.1+2503222 files, or that exact version patched with the DoF patcher. It checks game_plugin.dll in your game folder. If that file doesn't match, the connection indicator shows Version mismatch, a Different game version card appears on the left, and FMAX neither reads from nor writes to the game.

There are three possible causes:

  1. game_plugin.dll was changed while the game was running. Restart the game.
  2. Another patch or skin add-on modified game_plugin.dll. If the Connection status popover says Game file modified by another mod, click Turn on compatibility mode or enable Compatibility mode in Settings. Only the FMAX features that conflict with that patch are turned off, while everything else works as usual. If FMAX still won't connect in Compatibility mode, remove the patch and restore the original file. If you aren't sure how to undo the patch, right-click FM27 in your Steam Library → Properties → Installed Files → Verify integrity of game files to restore the original files, then relaunch the game.
  3. FM27 itself updated to a newer build. You'll need a new FMAX release updated for the new game version before FMAX can connect.
Careful

Verifying integrity resets every game installation file modified by any patch back to the original—not just game_plugin.dll. If you applied the DoF patcher, that will be undone too. Anything outside the game installation folder, such as skins in your Documents folder, is left untouched.

#Stuck on the startup screen

If the startup screen doesn't finish when launching FMAX, it shows the reason along with action buttons.

MessageMeaning
Couldn’t load game structure dataFMAX couldn't open its own data files. Restart FMAX.
FMAX stopped while starting upStartup or game detection didn't finish within 20 seconds. Restart FMAX.
Other messagesSame meaning as in the connection status table above.
  • Try again: Reopens the FMAX interface from scratch if it stopped during Preparing FMAX, or searches for the game again if it stopped while finding or reading the game.
  • Save log · Copy log: Captures a log to send to the developer. See Sending a developer log below.
  • Continue anyway: Dismisses the startup screen and opens the main list view.

If FMAX keeps stopping in the same place, please save the log and send it to the developer.

#Tactic files don't show up in the list

Tactic Arena, the Tactics screen, and Lock AI manager tactics in Live tweaks all list the tactic files (.fmf) inside your game's tactics folder. If a tactic you saved on FM's tactics screen isn't listed, the game may be saving files somewhere else (for instance, if you changed your user data location in game settings, or your Documents folder lives on another drive or in OneDrive).

Look at the Tactics folder line in any tactic picker to see which folder FMAX is currently reading and how it found it.

What you want to doWhat to do

Use a single file right awayDrag and drop the tactic file (.fmf) onto the FMAX window. Your original file stays put, and FMAX imports a copy into the list.
Remove an imported file from the listClick Remove next to that file on the Tactics folder line. Your original file isn't deleted.

Careful

After seeing 'Failed while writing to the game', always check your values before saving the game in FM—partially applied changes could otherwise be saved permanently into your save file.

If the Save button says Apply once connected and is disabled, the values on that tab weren't read from the currently running game. Once connected, click Reload from game (the circular arrow) on the tab.

#Edited values revert back

Check these in order:

  1. Did you click Save? If the 'Edited values' bar is still visible at the bottom of the tab, your changes haven't been written to the game yet. See Getting started.
  2. Did you save your game in FM? FMAX writes into the live running game in memory. If you reload your save without saving in FM first, those edits are lost.
  3. Did the game recalculate or update the value? Even after FMAX writes a value, the game continues updating things as normal—attributes shift with training and development, and transfer values change on days when FM recalculates valuations. Use Locks to hold a value steady; as long as FMAX is open, Locks writes your value back whenever the game changes it.
  4. Were Live tweaks or Locks turned off? Live tweaks and Locks only work while FMAX is running. When you reopen FMAX, they start paused if Restore previous state when FMAX starts is turned off in Settings.

We've received reports that edited Position familiarity reverts after advancing the in-game date. The cause hasn't been confirmed yet.

#White screen or 'out of memory'

Some users have reported that leaving FMAX open for a long time can turn the window white or show an 'out of memory' prompt asking to refresh.

  • 26.1107.1205 cut the FMAX interface's memory footprint to roughly a quarter, and 26.1107.1326 reduced it further by cleaning up data from closed tabs.
  • Not every underlying cause has been ruled out yet.

What to do:

  1. Check Current under Tools → Update notes on the left, and if you're on an older build, update to the latest version.
  2. If the window has already gone white, close FMAX and reopen it.
  3. If it still happens on the latest version, save a developer log and send it along with a note about which screen you were on and what you were doing.

#Updates or installation won't work

  • If clicking Install on an update notice shows 'Couldn’t install the new version', check When an update won't install for what to do based on the reason shown alongside it.
  • If the reason is manifest_policy, the FMAX you use is older than 26.1112.1754 (FMLE included) and the new release is made for a patched game; those older versions can't install such a release from inside the app. Download and run FMAX-setup.exe from getfmax.com once—your settings and lists carry over as is. From 26.1112.1754 on, updates no longer stop for this reason.
  • Check for updates in Settings looks for a newer version again at any time, for when you missed the notice at start (from the version that has the button).
  • If installing or uninstalling says 'FMAX hasn't closed yet', see When install or uninstall hangs.
  • If a blue "Windows protected your PC" window appears when running the installer, click More info → Run anyway. This appears because FMAX isn't signed with a paid code-signing certificate.

#Nothing happens when you run the installer

  • An antivirus program (such as V3) can quietly block an installer without a code signature. Check its scan log or quarantine for the FMAX installer. Some users finished installing after making a scan exception for it in V3 and running it again.
  • If FMAX-setup or FMAX_…_x64-setup is still listed in Task Manager, end it and run the installer again.
  • If it still doesn't work, tell us the file you ran, your antivirus, and whether the installer showed up in Task Manager even briefly.

#FMAX's window appears and closes right away

  • From 26.1112.1754, when FMAX closes unexpectedly it shows "FMAX closed unexpectedly" with an error code and writes the details to %APPDATA%\dev.fmle.desktop\crash.txt.
  • If that box mentions WebView2, download the WebView2 Runtime from Microsoft's website, install it and start FMAX again. It is what draws FMAX's screens.
  • If it closed with no message, an antivirus may have ended FMAX. If it ended before its window was fully up, crash.txt gets the entry "지난 실행이 창을 띄우기 전에 끝남" (the previous launch ended before its window; the file is written in Korean) the next time you start FMAX. If something ended it from outside after the window was up, there may be no record. Check your antivirus's scan log too.
  • When you ask for help, send the error code or crash.txt. The file contains no file paths from your PC or personal information.

#FMAX won't close

When you click the close button, FMAX first restores any live tweaks and game rules it modified before exiting. If it can't restore them, it stays open on purpose and shows 'Kept FMAX open because game rules couldn’t be restored' along with the reason. Check the reason and try closing again; if it persists, send a developer log.

If Stay when FMAX closes is turned on in Eri's settings, closing the window leaves FMAX running in the system tray. Right-click Eri in the tray to quit completely.

#Sending a developer log

FMAX keeps diagnostic logs ready to send to the developer when something goes wrong. Logs include the versions of FMAX, Windows, and your game files, where and why something stopped, and how long each step took. Folder names and save file names are omitted. Up to your last five launches are kept, so even if a run failed before finishing startup, you can still send its log the next time you open FMAX.

  1. Click the connection indicator in the top right to open Connection status. If you're stuck on the startup screen, use the buttons right on that screen instead.
  2. Under Developer log at the bottom of the popover, choose:
    • Save: Creates a text file starting with FMAX-log in your Downloads folder.
    • Copy: Copies the log to your clipboard so you can paste and send it on Discord or KakaoTalk.
  3. Include a brief note about which screen you were on and what you were doing when the issue happened.
