Basics

What FMAX remembers per save

Which data FMAX keeps separately for each save—such as Live tweaks, Locks, Bookmarks, and Shortlists—which settings apply across all saves, and how FMAX tells saves apart.

A regen (newgen) or agent generated in one save might be a completely different person—or nobody at all—in another save. That's why FMAX stores anything pointing to specific people or clubs separately for each save. When you open a different save in the game, FMAX switches over to that save's data automatically.

#Stored separately per save

FeatureWhat is stored per save
Live tweaksEnabled live tweaks and their target lists (growth, aging, youth, Prevent retirement, etc.), plus whether Live tweaks was turned on
LocksLocked values, 'Values to lock with the Lock button', and whether Locks was turned on
BookmarksSidebar Bookmarks list
ShortlistEvery player and staff shortlist
Change genderList of players with Keep men’s team eligibility
Match appearancePer-player Match appearance list
Stats & Record roomSeason-end records (recorded when 'Save season-end records' is enabled in Settings)
EriChat history, club management notes, and history of actions run from cards
Korean namesRecord of names FMAX changed in this save, used to revert them (applies when FMAX is in Korean)

'Recent edits' in the sidebar is not saved—it clears whenever you open another save.

#Shared across all saves

FMAX keeps a single copy of these on your PC, so they stay the same whichever save you open:

  • Every setting on the Settings screen (currency, wage display, hiding CA/PA, lock check interval, etc.)
  • Presets
  • Saved filters
  • Selected columns, sort order, and active filters on each list
  • Open tabs and theme
  • On/off toggles and the initial Check backup confirmation for Change gender and Match appearance, plus the on/off toggle and personal dictionary for Korean names
  • Initial Check backup confirmation for ⚡ Game editor and record editing

In a game with multiple human managers, your chosen 'My manager' is remembered by that manager's unique ID. If you open a save with different managers, FMAX asks you to pick again.

#How FMAX identifies your save

FMAX tells saves apart by the folder and file name of the save currently open in the game. You can check the active save under 'Current save' by clicking the connection indicator in the top right, or right beneath the page title on Live tweaks and Locks where it shows 'Current save: Name'.

SituationWhat FMAX does
You start a new game and haven't saved yetStores everything separately under 'Unsaved new game'. The first time you save, FMAX carries it seamlessly over to the new save name.
You load a different save in the gamePauses and saves your current save's Live tweaks and Locks, reloads the lists, and loads the other save's data.
You reload the same saveShows 'Save reloaded · Reloading lists' and refreshes your lists and tabs. Everything stored for that save stays intact.
You Save Game As under a new name in the gameCopies your Live tweaks, Locks, Bookmarks, Shortlist, Keep men’s team eligibility, Match appearance, and season records straight over to the new name without pausing. The old save name keeps its own separate copy too.
You open an unfamiliar save whose file is identical to a known save (a copied save file, or a backup FM created before overwriting)Carries over that save's Live tweaks, Locks, Bookmarks, Shortlist, Keep men’s team eligibility, Match appearance, and season records, and shows 'Same file as save ‘Name’'.
You open a save FMAX has never seen beforeStarts with Live tweaks and Locks empty.

Whenever the save changes, a notification shows 'Save switched: Name' along with what was turned back on (for example, 'Restored previous state: 3 live tweaks · 5 locks'), or tells you 'Live tweaks and Locks are turned off for this save' or 'First time opening this save—Live tweaks and Locks are empty'.

Good to know

While FM is still loading a save, the new file name becomes visible before the previous save's date clears. FMAX waits until loading finishes before deciding, so it won't mistake loading a save for 'Save Game As'.

#When you restart FMAX

If 'Restore previous state when FMAX starts' is enabled in Settings, FMAX turns back on whichever Live tweaks, Locks, Keep men’s team eligibility, and Match appearance settings were active when you closed FMAX.

  1. Right on launch, FMAX loads the data from your last opened save without applying it to the game yet. Under the title on Live tweaks and Locks, it shows 'Last opened save: Name · Switches to another save's data if you open a different save in the game'.
  2. Once FMAX confirms which save the game has open, it turns back on only what belongs to that save and shows 'Restored previous state'.
  3. If the game doesn't report the save name, FMAX keeps using the loaded data as is and shows 'Couldn’t read save name from game … keeping as is' under the title.

Turn this setting off if you prefer everything to start paused—you can turn features back on manually on each screen.

Careful

If you have players set to Keep men’s team eligibility and loaded your save while FMAX was closed, reload the save once after opening FMAX. The game builds its squad registration lists at the moment a save loads.

#Data from before per-save storage

If you had Live tweaks, Locks, Bookmarks, or other data saved from before FMAX stored data per save, FMAX asks once the first time you open a save that has nothing stored yet:

  • Title: 'Assign your previously saved data to ‘Name’?'
  • Assign to this save: Makes that data belong to this save and doesn't ask again.
  • No: Starts this save empty and asks again the next time you open another new save.

Nothing from that earlier data is applied to the game until you answer.
