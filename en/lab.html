Official test and Tactic Lab

An Official test runs every FMAX user's tactic with the exact same club, squad, and opponents. Run it from the 'Official test' tab in the Tactic Arena to save results to your Tactic Lab account and upload your tactic.

#What is the Official test?

You'll find it in Official test, the fifth tab of the Tactic Arena.

Tests you run with your own test sheet use whichever teams and opponents you picked, so it's hard to compare your numbers directly with someone else's. An Official test puts every FMAX user on equal footing—the exact same club, the exact same squad, and the exact same opponents. Because the setup never changes, anyone can test anywhere and compare results side by side.

Pick a tactic file and press start: FM27 plays out the matches for you and reports the tactic's Season points (the points you can expect over a 38-match season).

Tactic Lab is where all of those results come together. Every Official test you finish is recorded to your Tactic Lab account, and any tactics you upload can be viewed by other players.

Good to know

If you see 'Tactic Lab is not open yet', Official tests aren't available at the moment. In the meantime, you can still compare tactics head-to-head with your own test sheet in the Run tests tab.

#Before you start

#Readiness check

Opening the tab runs a quick check first. Every row needs to say 'Passed' before you can start. Any row that doesn't pass explains what's wrong and how to fix it—once you've sorted it out, click Check again.

CheckWhat it looks for
Game connectionWhether the game is running with a save loaded
Match engineWhether your game version and match engine are supported for Official tests. Match engine mods will fail this check
Test clubsWhether the two clubs set on the test sheet are available in the current save. If not, stand-in clubs are used instead
The game’s default tacticsWhether the game’s default tactics used by opponent clubs are unmodified. Everyone needs the original files so you face the exact same opponents
Tactic Lab accountWhether an account is linked to record your results

Stand-in clubs step in when the official clubs aren't playable in your current save. FMAX matches their squads and club conditions to the official clubs, so the result counts as the exact same test—it simply leaves a note that stand-in clubs were used.

#Linking your Tactic Lab account

  1. On the Tactic Lab account row of the check list, click Link account. Your browser will open.
  2. Sign in with Discord in your browser. Make sure the confirmation code shown in your browser matches the confirmation code in FMAX, then confirm the link.
  3. Once you're signed in, the row in FMAX automatically updates to 'Linked as …'.
  • FMAX never sees or receives your Discord password.
  • Click Unlink to disconnect your account. Results already recorded on Tactic Lab stay there, though you won't be able to run Official tests or upload tactics until you link again.

#Running a test

  1. Choose a tactic to test. Pick from the tactic files in your game's tactics folder—any tactic you've saved on FM27's tactics screen shows up here. If a tactic you just saved isn't listed, click Refresh list. Still missing? Click Choose folder on the Tactics folder row right below to point FMAX to the right folder, or drag and drop a tactic file (.fmf) straight into the FMAX window.
  2. Choose how accurately to test. Pick Precise, Standard, or Fast. If it's your first run, Standard is a good place to start.
  3. Review the tactic, match count, and estimated time on the card on the right, then click Start official test. FMAX will ask you to confirm once more.

Playing more matches narrows the range and gives you a firmer result, at the cost of taking longer.

OptionMatchesWhen to use
Precise1,000 matchesPinpoint accuracy when separating tactics on the leaderboard
Standard (recommended)400 matchesPlenty accurate for most tests
Fast200 matchesQuick ballpark check
Careful

While a test is running, please follow these rules: don't advance the date in-game (don't click Continue), don't save the game or load another save, and don't close FM27 or FMAX. If the game date moves forward or a save is loaded, the test stops on the spot.

In Live tweaks, Lock AI manager tactics and 100% tactical effectiveness pause automatically while the test runs and turn back on once it finishes.

#While a test is running

The whole tab switches to a progress view showing the matches left, a progress bar, the tactic, total matches, and the clubs.

Click Stop test to pause at any time. All matches played so far are kept, and you can pick up right where you left off from the same save on the same game date.

#Resuming a stopped test

A stopped test stays pinned as a card at the top of the tab, telling you why it stopped and which game date you need in order to resume.

  • Resume: Click this while the save you started the test in is open on that exact game date.
  • Start new: Leave the stopped test as it is and start a fresh run with your choice of tactic and match count.
Why it stoppedWhat to do
Stopped because the game date advancedIf you haven't saved, reload the save to return to that date and click Resume. If you've already saved past it, you can't resume—click Start new
Stopped because a save was reloadedIf it's the same save on the same date, go ahead and click Resume
Stopped because a different save was loadedReload the save you started the test in, then click Resume
Stopped because the game stopped respondingOnce the game is responsive again, click Resume

Tests started more than 7 days ago can no longer be resumed, though the matches played up to that point remain in your records.

#Reading your results

When the run finishes, a result card appears.

  • Season points: The points you can expect over a 38-match season with this tactic. Higher means a stronger tactic.
  • Range: How much match-to-match luck can sway the score. Your tactic's true points almost certainly sit inside this span. More matches narrow the range; if two tactics' ranges overlap, it's still too close to tell which one is stronger.
  • Matches played and W-D-L.

If you've tested the same tactic more than once, FMAX also shows the combined totals across your past runs. View details in Rankings opens that tactic's record in the Tactic Arena's Rankings.

Under Past official tests below, you'll see every test started on this PC. Click 'View results' for completed runs or 'Resume' for stopped ones.

#What gets recorded and uploaded to Tactic Lab

#Result summary saved automatically

As soon as an Official test finishes, a result summary is automatically saved to your Tactic Lab account. You'll see this same notice next to the start button too.

CategoryWhat's included
ScoreWins, draws, losses, goals scored, and goals conceded against each opponent
Test conditionsGame version and FMAX version, game file type, game date, test clubs, active live tweaks, and the tactic file name
Progress logWhen the test ran and why it stopped (if it did)

The tactic file itself, detailed match logs, your save name, and manager or player names are never included.

If saving the summary fails, the result card lets you know—just click Resend.

#Uploading to the Tactic Lab

To let other players see and download your tactic, click Upload to the Tactic Lab on the result card. This sends your tactic file along with the match records from that test. Your tactic file is sent only when you click this button.

Uploading alone doesn't make the tactic public right away. A publish page opens in your browser where you fill in a title and description before it goes live. If the browser window doesn't show up, click Reopen publish page.

#Korean and English

Use Korean / English at the top of the Official test tab to switch the language of this tab on its own. Other screens stay in Korean (when FMAX is set to Korean).
