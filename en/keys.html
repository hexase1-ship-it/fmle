Basics

Keyboard shortcuts

Every keyboard shortcut in FMAX, grouped by screen—for switching tabs, saving, Quick open, selecting list rows, and editing values.

When you hover over a button and see a key badge in its tooltip, that's its keyboard shortcut. All shortcuts below work only when the FMAX window is in focus.

#Anywhere

KeyWhat it does
Ctrl+KOpens or closes Quick open. Search by name or Unique ID to open an item in a tab. Tabs and Quick open
Ctrl+SSaves unsaved edits across all open tabs to the game at once. When edits are written to the game
Ctrl+GOpens the player, staff member, club, or team you're currently viewing in-game in a tab.
Ctrl+JOpens or closes the Eri chat panel. Eri
F1Opens this wiki's guide for the screen you're currently viewing. Also works inside the filter window.
Ctrl+WCloses the current tab.
Ctrl+Shift+WCloses all open tabs and returns to the list.
Ctrl+Shift+TReopens the last closed tab along with any unsaved values it had. Press repeatedly to bring back earlier closed tabs.
Ctrl+TabMoves to the next tab. The list screen counts as one stop.
Ctrl+Shift+TabMoves to the previous tab.
Ctrl+1Switches to the list screen.
Ctrl+2 ~ Ctrl+8Jumps to the first through seventh tab from the left.
Ctrl+9Jumps to the last tab.
EscCloses one open item (see below).

Esc closes one thing at a time, in this order:

  1. An open field picker (such as from Add column)
  2. An open menu (right-click menu, Columns, Saved filters, ⚡ menu, etc.)
  3. Quick open
  4. The Connection status popover
  5. Clears all selected rows in a list or in a Club tab table (when your cursor isn't inside a text box).

Floating help tooltips also close with Esc.

#List screen

KeyWhat it does
Ctrl+FMoves focus to the search box.
Ctrl+Shift+FOpens the filter window.
Ctrl+ASelects all currently visible rows, or clears the selection if all are already selected. When inside a text box, selects the text in that box instead.

After clicking the list once to focus it, you can use these keys:

KeyWhat it does
↑ ↓Moves up or down one row.
PageUp PageDownMoves up or down one screenful.
Home EndJumps to the very top or bottom.
EnterOpens that row in a tab.
SpaceSelects or deselects that row.
EscClears all selected rows.
Menu key or Shift+F10Opens the right-click menu for that row—or for an underlined name if focus is on one.

Keys used together with the mouse:

KeyWhat it does
Shift + click a row or checkboxSelects every row from the last row you clicked to this one.
Ctrl + click a rowSelects or deselects that row without opening its tab.

Rows under Bookmarks, Recent edits, and My manager & club in the sidebar can be focused with Tab and opened with Enter.

#Quick open

KeyWhat it does
↑ ↓Moves through the results.
EnterOpens the highlighted result in a tab.
Esc or Ctrl+KCloses Quick open.

#Edit tabs

#Subpages and field rows

KeyWhat it does
↑ ↓When focus is on the subpage list on the left: moves to the previous or next subpage. When focus is on a field row: moves up or down one row.
Home EndJumps to the first or last subpage on the left.
Enter or SpaceStarts editing the focused field row.
EnterWhen focus is on an underlined name, opens that item in a tab.
Ctrl+AOn the Squad and Staff pages of a Club tab: selects all rows in the table, or clears the selection if all are selected.

#Editing numbers

Clicking a numeric row opens a − number + stepper box.

KeyWhat it does
Type a numberUpdates immediately as you type.
↑ ↓Steps the value up or down by one increment.
Shift+↑ Shift+↓Steps up or down in larger jumps—by 5 for single-step fields like attributes and positions, or by 10× a single step for everything else.
Shift + click − / +Makes the same large jump as above.
Mouse wheel over the boxSteps up or down by one increment.
EnterKeeps the value and closes the box.
EscReverts to the value from before you opened the box and closes it.
Tab / Shift+TabKeeps the value and immediately opens the next or previous row.

For money amounts, a single step is a clean round figure in your chosen currency (for example, ₩100M in Korean won).

#Other fields

FieldKeys
Date, color, and dropdown fieldsEnter to keep the value, Esc to revert
Header number cards (Current ability, etc.)Click and type, then Enter to keep the value or Esc to revert
Numbers inside lists (language proficiency, relationship rating, etc.)Focus and press Enter or Space to open, then Enter to keep or Esc to revert

Values changed here are written to the game only when you click 'Save' (Ctrl+S).

#Filter window

KeyWhat it does
Ctrl+EnterApplies the current conditions to the list (Apply to list).
EnterWhen pressed in a condition's value box, applies the filter to the list.
EscCloses an open field picker.
F1Opens the filter help page.

#Field picker (Add column, filter conditions)

KeyWhat it does
Type lettersSearches by field name.
↑ ↓Moves through the fields.
EnterAdds the highlighted field.
EscCloses the picker.

#Confirmation and naming dialogs

KeyWhat it does
EnterConfirmation dialog: clicks the right-hand (confirm) button. Naming dialog: confirms the name you typed.
EscCancels.

In value input dialogs opened from the ⚡ Game editor, Esc cancels.

Careful

In confirmation dialogs, Enter triggers the right-hand button—such as 'Apply', 'Remove', or 'Yes, backed up'. For dialogs that write straight to the game, read the message carefully before pressing Enter.

#Eri

KeyWhat it does
Ctrl+JOpens or closes the chat panel.
EnterSends what you typed.
Shift+EnterStarts a new line.
↑ ↓, Enter or Tab, Esc in the Name list after @Picks a name or closes the list.

In the API key and note fields on the Eri panel, Enter saves. See Eri for details.

#Korean names

In the box for editing a name spelling, Enter saves and Esc cancels (this tab appears only when FMAX is in Korean). Korean names

#When shortcuts don't apply

  • While the player appearance picker window is open, shortcuts for switching tabs, saving, and Quick open are paused. Close that window first.
  • Ctrl+A won't select list rows while a confirmation dialog is open or while your cursor is inside a text box.
  • Ctrl+F and Ctrl+Shift+F work only on the list screen.
