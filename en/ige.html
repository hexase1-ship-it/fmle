Game editor

Game editor (⚡)

The ⚡ button at the top of edit tabs runs FM's built-in editor actions—transfers and loans, clearing injuries and unhappiness, terminating contracts, adding homegrown status, and more—straight from FMAX. Once confirmed, changes apply to the game immediately without advancing the date, and cannot be undone.

#What are in-game editor actions?

FM27 has its own In-Game Editor (a paid add-on). FMAX's ⚡ menu does the same jobs, but instead of going through the In-Game Editor, it runs the game's own routines directly—so you can use it even if you haven't bought the In-Game Editor.

  • Changes apply right away. As soon as you click 'Apply now' in the confirmation prompt, the game updates on the spot. You don't need to advance the date or click 'Save'.
  • They cannot be undone. FMAX has no 'Revert' for these actions. Where an opposite action exists (Freeze attributes ↔ Unfreeze attributes, Grant work permit ↔ Remove work permit, and so on), simply run the opposite action instead.
  • No In-Game Editor usage is recorded. Because FMAX doesn't go through the In-Game Editor, your save isn't marked as having used it.
  • Use them while the game is stopped. As the first-time confirmation prompt notes, run these actions when the game is paused on a screen rather than while days are advancing.
Written to the game at once

Every action in the ⚡ menu writes straight to the game as soon as you confirm it. It doesn't wait for 'Save' on the edit tab.

Careful

These actions cannot be undone. Save a separate backup of your save file before using them for the first time.

#Where to find it

  • The ⚡ button at the top right of an edit tab (labelled 'In-game editor actions'). It appears only on the Player, Staff, Team, Club, and My manager tabs—not on other tabs such as Competition, Nation, or City.
  • Right-click menus in lists also include a group starting with '⚡'. Right-clicking a single person opens their tab and runs the action just as if you picked it from the ⚡ menu. Selecting multiple people and right-clicking shows the '⚡ Quick actions' group (Applying to multiple people at once). For the full right-click menu, see Tabs, quick open, and right-click menus.
  • To open the My manager tab, click your manager's name under 'My manager & club' on the left.

The ⚡ button is available only while FMAX is connected to the game and after the tab has read its data from the game. If FMAX isn't connected or is busy writing something else, it shows 'Not available right now'.

#How to use it

  1. Open a Player, Staff, Team, Club, or My manager tab.
  2. Click the ⚡ button and choose an action from the menu.
  3. If the action needs extra details (such as a destination club, homegrown club, or morale level), pick them in the next menu or terms window.
  4. When you use it for the first time, FMAX asks 'Have you backed up your save?' Click 'Yes, backed up' and it won't ask again.
  5. Every action shows a confirmation prompt titled 'Name · Action', explaining what will change and reminding you that it cannot be undone. Click 'Apply now' to run it, or cancel to leave everything untouched.
  6. When done, a '…: Applied to game' notice appears and the tab redraws with the updated values. The action is also logged under 'Recent edits' on the left as 'Game editor · <action name>'.

For major actions—such as transfers, terminating a contract, or national team changes—the confirm button is red.

#'Upcoming transfer' and 'Set to retire' under the name

On the Player, Staff, and My manager tabs, any scheduled future events in the game appear below the person's name (only when present).

  • Upcoming transfer · Club · Date · Transfer fee: An agreed future move. Moves agreed on a free at the end of a contract show 'No fee'. This same line also appears at the top of the ⚡ menu.
  • Set to retire · Date: The retirement date set by the game (for players and staff).

The menu only shows options that fit the player's current state.

  • 'International retirement' appears only for players who haven't retired internationally; 'Cancel international retirement' appears only for those who have.

#Team tab menu

Actions on the Team tab apply to every player contracted to this team.

GroupActionWhat it does

When finished, the notice also reports 'Applied to N players'.

Change team morale lets you choose from 20 levels, from '20. Perfect' down to '1. Abysmal', with 20 as the highest. The game clamps each player within the range it allows for them.

Careful

Team cohesion, tactical familiarity, and the overall team morale value only change when the game is in a state that accepts them. If it isn't, FMAX does not run cohesion or tactical familiarity and shows 'The game is not accepting this action right now'. For team morale, FMAX updates the players' individual morale and notes 'Team-wide morale was left unchanged because the game is not accepting it right now' (for a national team, it doesn't run at all). FMAX does not alter that state itself, and which saves are in that state has not yet been confirmed.

Removing an objective reads the club's current objectives from the game and lists them. Recognised objectives appear by name—such as 'Youth Development', 'Possession football', or 'Sign high-reputation players'—while unrecognised ones appear as 'Objective type <number>'. Objectives tied to a specific player or club include their name alongside it. Pick one to open the confirmation prompt.

Good to know

When a club has several similar objectives, the game deletes the earliest one first. If that would remove a different objective from the one you picked, FMAX stops without running it and lets you know.

Right-clicking a club also shows the '⚡ All club players' group: Remove all player injuries, Remove all player bans, and Remove all player unhappiness. These apply to every player at the club at once (Applying to multiple people at once).

#Choosing a club (transfers, loans, and moves)

A search menu lets you find a club by name; the person's current club is excluded. So you can tell apart men’s clubs and women’s clubs that share a name, 'Women’s team' or 'Men’s team' and the nation appear below each name. Choosing a club sends them to its first team.

#Staff transfers: choosing a job and terms

  1. Picking a club opens a list of the jobs the game offers this person (each shown alongside its team, such as First Team, B Team, or Youth team). Jobs the game doesn't allow are hidden.
  2. Picking a job opens the terms window with 'Fee (compensation)' (0 means free), plus Weekly wage and Contract expiry under 'New contract (added by FMAX)'.
  3. If you choose Manager, Player/Manager, or Assistant Manager, whoever currently holds that job steps down.

If FMAX hasn't read the person's current wage yet, the Weekly wage toggle starts turned off so they aren't accidentally moved onto a 0 wage.

#Add to national team (Staff) and Move to another national team (My manager)

  1. Search for and choose a nation.
  2. A list of that nation's national teams appears (senior and youth, men's and women's).
  3. For staff, next choose one of the jobs the game offers. Picking Manager or Assistant Manager replaces the current holder, and depending on the job, the game may also end their club contract.
  4. For My manager, you skip job selection and join directly as Manager.
  5. Click 'Apply now' in the confirmation prompt. The game sets the contract terms.

If that national team is managed by a human manager, FMAX will not place someone into its Manager job.

  2. Pick a rule specifying how many years and at what ages they trained at that club or in that nation.
  3. Search by name below and click the club or nation to open the confirmation prompt.

#Count as EU player

Only current member nations of the EU, EEA, and EFTA (European Union, European Economic Area, and European Free Trade Association) are listed, excluding any nationalities the player already holds. Picking a nation adds it as an extra nationality marked 'Not Eligible For Nation'.

  • Under EU player rules, they count as a European player.
  • They cannot be called up to that nation's national team.
  • League-specific EU rules and work-permit checks are still handled by the game as normal.

#Change nationality and Change city of birth

Search by name and choose from the list; their current nationality or city is excluded. Because many cities share the same name, each city is listed alongside its nation. Changing primary nationality leaves their Other nationalities list and international eligibility records intact.

#Change retirement date

A date field opens with their current retirement date filled in. You can pick any date from tomorrow onwards; choose a date and click 'Change' to open the confirmation prompt. To block retirement altogether, use 'Prevent retirement' in Live tweaks.

#Applying to multiple people at once

The actions below can be applied to several people at once—none require extra choices, and each affects only that individual.

  • Players: Remove all injuries, Remove all bans, Remove all unhappiness, Freeze attributes, Unfreeze attributes, Grant work permit, Remove work permit, International retirement, Cancel international retirement, Mark military service done, Mark military service exempt, Clear military service record
  • Staff: Change to female, Change to male

There are three ways to run them:

  1. Select multiple people in a list and right-click → choose from the '⚡ Quick actions' group.
  2. Right-click a club → '⚡ All club players' (clears injuries, bans, or unhappiness). This runs on every player at the club, and you can select multiple clubs at once.
  3. Add to a preset: You can pick 'Game editor actions (apply immediately)' as a preset action so it runs together with field edits in one go (Presets).

Whichever way you start it, a single 'Apply "<action>" to N people' confirmation prompt appears. FMAX runs the action one person at a time, showing progress as 'Applying in-game editor action: N / total', and leaves anyone already in that state untouched. When finished, a notice shows how many succeeded and failed.

Careful

Batch in-game editor actions cannot be undone either. Clicking 'Revert' on a preset notice only reverts edited field values—not in-game editor actions.
