Help

Frequently asked questions

Answers to common questions about administrator rights, which installer to download, how long changes last, and using FMAX alongside other mods.

#Installation and running FMAX

#Do I need to run FMAX as administrator?

No. Both installing and running FMAX work without administrator rights—FMAX installs only to your own Windows user account.

There is one exception: if you run FM27 as administrator, you must run FMAX as administrator too. Otherwise, the connection badge shows No access.

#Where do I download the installer?

You only need FMAX-setup.exe from getfmax.com. Every time you run it, it downloads and installs the newest version. See Installing, updating and uninstalling for details.

#Do updates bring new features?

Yes—new features arrive in new releases. Every time you launch an installed copy of FMAX, it checks for updates and shows a banner with an Install button when a newer version is available. Clicking Install updates FMAX while keeping all your settings and lists intact. See Updating to a new version.

You can check your current version and read the changelog for every release under Tools → Update notes on the left.

#Do I need to reinstall or set up FMAX again for each save?

No. FMAX connects to whichever save is currently open in FM27, whether it's a brand-new save or an existing one.

Live tweaks, Locks and favourites are stored separately per save. When you load a different save, FMAX reloads its lists and switches to that save's setup automatically. See What FMAX remembers per save for details.

#Is FMAX made with Cheat Engine?

No. FMAX doesn't use Cheat Engine and doesn't require installing any extra software. FMAX reads and writes values in the running FM27 process entirely on its own.

#Does it work on Mac or with other FM games?

FMAX is a Windows 10 and 11 (64-bit) desktop app. It only reads and writes FM27 version 27.0.1+2503222, and won't connect to other FM titles or different FM27 builds.

#What happens when FM27 updates?

When the game version changes, FMAX shows Version mismatch on the connection badge and won't read from or write to the game. You'll need an updated FMAX release built for the new game patch before you can use it again.

#Edited values

#How long do my changes last?

It depends on how you made the change:

How you changed itWhen you close FMAXSaved in your save file?
Edit on a tab and click SaveStays as is—the value is already in the game.Yes, once you save the game in FM.
⚡ In-game editor actionsWritten into the game immediately as soon as you click Apply now in the confirmation dialog, and stays there. There is no undo.Yes, once you save the game in FM.
Live tweaksStops. Live tweaks only run while FMAX is open.Whether changes already made stay behind depends on the tweak.
LocksStops. FMAX no longer holds the value in place, so the game can change it again from then on.Whatever value is in the game at that moment stays if you save in FM.
  • If you reload your save without saving in FM first, any changes made with FMAX are lost.
  • Even after you write a value with Save, the game still updates it normally over time—for instance, attributes continue to rise and fall through training and player development. Use Locks to hold a value steady.
  • Some live tweaks undo their changes when turned off (for example, turning off Max extra staff slots restores only the slots FMAX raised). See Live tweaks for how each one behaves.
  • When you reopen FMAX, any Live tweaks, Locks and Keep men’s team eligibility that were on when you closed it turn back on for that save according to Restore previous state on launch in Settings (enabled by default).

For which changes apply right away and which require advancing the in-game date, see When changes take effect in the game.

#If I raise CA, do attributes go up automatically?

Changing Current Ability (CA) in FMAX only changes the CA number itself—attributes stay where they are. We haven't verified whether the game gradually adjusts attributes toward the new CA later on.

Going the other way, if you've edited attributes and want CA to match them, click Set CA to this on the Recommended Current Ability (RCA) card near the top of the Player tab. That sets CA equal to Recommended Current Ability, and still requires clicking Save to write to the game. Recommended Current Ability is calculated from attributes and positions using the exact same method the game uses.

#CA and Recommended Current Ability (RCA) don't match—is FMAX wrong?

No—those two numbers differ for most players inside the game itself. CA is the rating assigned to the player by the game, while Recommended Current Ability is calculated separately by the game from the player's current attributes and playable positions ("for these attributes, CA would be around this"). A difference of 1–3 points is typical; in an actual save, only about one in three players had the exact same number for both.

Older versions of FMAX used an approximate calculation for Recommended Current Ability, which could differ from the Game editor by a few points. FMAX now follows the game's own calculation directly.

Reload from game (the circular arrow in the tab header) simply re-reads the current values from the game—it doesn't calculate or alter anything.

#Does the Youth CA & PA live tweak only apply to my club?

You choose a target for each rule: All players, Club, Single player, Nation, League or Nationality. While FMAX is open, the rule applies to newly generated youth players matching that target. A 'Single player' rule applies once right away to the player you pick. See Live tweaks for details.

#Using FMAX with other mods

#Can I use FMAX with skins or other patches?

When connecting, FMAX checks the game file game_plugin.dll. FMAX connects right away if this file is the unmodified FM27 27.0.1+2503222 file, or the original file patched with DoF Patcher.

  • Patches or skin add-ons that modify this file will trigger Version mismatch on the connection badge. As long as the file's structure still matches the original, you can turn on Compatibility mode to use them together—only the FMAX features that overlap with that patch are disabled. If Compatibility mode still doesn't work, you'll need to remove that patch. See Troubleshooting for steps.
  • Skins and mods that don't modify this file won't trigger FMAX's connection check, though we haven't tested every mod combination.

#Can I use FMAX alongside the FM27 AI Value mod?

The FM27 AI Value mod does the same thing as FMAX's Value my players like AI clubs live tweak. If both are enabled, FMAX detects that the mod has already turned it on and leaves it alone. On the Live tweaks screen, you'll see 'Already enabled by another installed mod (FM27 AI Value) · FMAX leaves it untouched', so keeping both on won't apply the effect twice.
