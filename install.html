시작하기

설치·업데이트·지우기

설치 파일 하나를 받아 관리자 권한 없이 설치하고, 새 판은 FMLE 안에서 물어본 뒤 설치합니다. 지울 때 주의할 점도 적었습니다.

#필요한 것

  • Windows 10 또는 11(64비트)
  • FM27 판 27.0.0+2493426. 판이 다르면 FMLE가 게임에 연결하지 않습니다.

FMLE는 게임 파일을 고치지 않습니다. FMLE가 켜져 있는 동안 실행 중인 게임의 값을 읽고 씁니다.

#설치 파일 받기

설치 파일은 FMLE Releases 페이지에서만 받습니다. 다른 곳에서 받은 파일은 FMLE가 업데이트할 때 쓰는 서명을 확인할 수 없습니다.

페이지에 파일이 여러 개 보이지만 받을 것은 FMLE_판번호_x64-setup.exe 하나입니다.

파일받아야 하나무엇인가
FMLE_…_x64-setup.exe받습니다설치 파일입니다.
FMLE_…_x64-setup.exe.sig받지 않습니다설치 파일의 서명입니다. FMLE가 업데이트할 때 스스로 읽습니다.
latest.json받지 않습니다새 판 안내문입니다. FMLE가 업데이트할 때 스스로 읽습니다.
fmle-release.json과 .sig받지 않습니다함께 배포된 파일을 확인하는 목록과 서명입니다. FMLE가 업데이트할 때 스스로 읽습니다.
Source code (zip, tar.gz)받지 않습니다GitHub가 자동으로 붙이는 묶음입니다. FMLE 프로그램이 아닙니다.

#설치하기

  1. 받은 FMLE_…_x64-setup.exe를 실행합니다.
  2. 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보를 누르고 실행을 누릅니다.
  3. 다음 → 설치 → 마침을 누릅니다. 마침 화면에서 바탕화면 바로가기 만들기를 켜 두면 바탕화면에도 FMLE가 생깁니다.

"Windows의 PC 보호" 창은 FMLE에 유료 코드 서명 인증서가 없어서 뜹니다. 위 Releases 페이지에서 받은 파일이라면 실행해도 됩니다. 브라우저가 받는 단계에서 비슷한 경고를 띄울 수도 있습니다.

설치하면 이렇게 됩니다.

  • 내 Windows 계정에만 설치됩니다(%LOCALAPPDATA%\FMLE). 관리자 권한은 필요 없습니다.
  • 시작 메뉴에 FMLE가 생깁니다.
  • Windows 설정 → 앱 → 설치된 앱에 FMLE가 생깁니다. 지울 때 여기서 지웁니다.

설치가 끝나면 처음 시작하기로 넘어갑니다.

설치 폴더의 파일은 함께 둡니다. fmle.exe 하나만 다른 폴더로 옮기거나 서로 다른 판의 파일을 섞지 않습니다. 필요한 파일이 빠지거나 손상되면 FMLE가 실행을 멈추고 안내합니다. 이때는 위 Releases 페이지의 설치 파일로 다시 설치합니다. 설정과 목록을 남기려면 "애플리케이션 데이터 삭제하기" 를 체크하지 않습니다.

#새 판으로 업데이트하기

설치한 FMLE는 켜고 몇 초 뒤 새 판이 있는지 한 번 확인합니다. 새 판이 있으면 "새 판 …이 나왔습니다 · 지금 쓰는 판은 …입니다" 알림이 설치 단추와 함께 30초 동안 뜹니다.

  1. 알림의 설치를 누릅니다.
  2. "새 판 …으로 바꾸시겠습니까?" 창이 뜹니다. 설치를 누르면 진행하고, 나중에를 누르면 그만둡니다.
  3. '새 판을 받고 있습니다'와 받은 양(%)이 보입니다.
  4. '설치를 준비하고 있습니다 · FMLE가 곧 꺼졌다가 다시 켜집니다'가 뜨고 FMLE가 닫힙니다.
  5. 설치가 끝나면 새 판 FMLE가 저절로 켜집니다.

업데이트 중에 FMLE가 하는 일은 이렇습니다.

  • 받은 파일이 정말 FMLE 것인지 서명으로 확인한 뒤에만 설치합니다. 서명이 맞지 않으면 설치하지 않습니다.
  • 설치하기 전에 FMLE가 게임에 걸어 둔 치트와 규칙을 잠깐 풉니다. 새 FMLE가 켜지면 설정의 FMLE를 다시 켜면 지난번 상태 그대로에 따라 다시 켜집니다. 이 설정이 꺼져 있으면 모두 멈춘 채로 시작하니, 각 화면에서 다시 켭니다.
  • 남자팀 자격 유지를 쓰는 중이었다면, 다시 켠 뒤 세이브를 다시 불러오라는 안내가 뜰 수 있습니다.
  • 설정, 프리셋, 영입 명단, 치트·고정 목록 같은 FMLE의 기억은 그대로 남습니다.

알림을 놓쳤거나 나중에를 눌렀다면, 다음에 FMLE를 켤 때 다시 알려 줍니다.

#손으로 업데이트하기

Releases 페이지에서 새 설치 파일을 받아 실행해도 똑같이 업데이트됩니다. 설정과 목록은 그대로입니다.

주의

설치 중에 제거 화면이 뜨면 "애플리케이션 데이터 삭제하기" 는 체크하지 않습니다. 체크하면 FMLE가 기억해 둔 설정과 목록이 모두 지워집니다.

#지금 쓰는 판 확인하기

왼쪽 도구의 업데이트 노트에 '지금 쓰는 판은 …입니다'가 보이고, 목록에서 그 판에 '지금 쓰는 판' 표시가 붙습니다. 판마다 무엇이 바뀌었는지도 여기서 봅니다(설정과 업데이트 노트).

#업데이트가 안 될 때

설치하지 못하면 '새 판을 설치하지 못했습니다'와 함께 까닭이 뜹니다.

까닭할 일
인터넷 연결을 확인해 주세요새 판을 받지 못했습니다. 인터넷 연결을 확인하고 다시 누릅니다.
서명이 맞지 않아 설치하지 않았습니다받은 파일이 FMLE 것으로 확인되지 않아 설치하지 않았습니다. 지금 쓰는 FMLE는 그대로입니다.
게임 코드를 되돌리지 못했습니다. FMLE를 다시 켜 주세요치트를 풀지 못해 설치를 멈췄습니다. FMLE를 껐다 켠 뒤 다시 합니다.
설치 프로그램을 열지 못했습니다. FMLE를 다시 켜 주세요FMLE를 껐다 켠 뒤 다시 합니다. 계속되면 Releases 페이지에서 설치 파일을 받아 직접 실행합니다.
이미 설치하고 있습니다설치가 진행 중입니다. 기다립니다.
이미 최신 판입니다받을 새 판이 없습니다.

#지우기

  1. Windows 설정 → 앱 → 설치된 앱을 엽니다.
  2. FMLE 옆 메뉴에서 제거를 누릅니다.

FMLE가 켜져 있으면, 제거 프로그램이 먼저 FMLE를 닫습니다. 이때 FMLE는 창의 닫기 단추를 누를 때와 똑같이 게임에 걸어 둔 치트와 규칙을 원래대로 돌린 뒤 닫힙니다.

제거 화면의 "애플리케이션 데이터 삭제하기" 는 이렇게 다릅니다.

체크하면체크하지 않으면
FMLE가 이 PC에 기억해 둔 것(설정, 프리셋, 저장한 필터, 영입 명단, 즐겨찾기, 세이브마다 기억한 치트·고정 등)이 함께 지워집니다.남아 있다가, 다시 설치하면 그대로 돌아옵니다.
주의

"애플리케이션 데이터 삭제하기"로 지운 FMLE의 기억은 되살릴 수 없습니다. 다시 설치할 생각이 있다면 체크하지 않습니다.

FMLE를 지워도, 이미 게임에 쓴 값과 FM에서 저장한 세이브는 그대로입니다.

#설치나 제거가 멈출 때

설치·업데이트·제거 프로그램은 파일을 바꾸기 전에 켜져 있는 FMLE를 닫습니다. 60초 안에 닫히지 않으면 "FMLE가 아직 닫히지 않았어요. FMLE 창에 뜬 안내를 확인하고 FMLE를 닫은 뒤 다시 해 주세요." 창을 띄우고 멈춥니다. 설치된 FMLE는 바뀌지 않습니다.

FMLE는 게임에 걸어 둔 것을 원래대로 돌리지 못하면 일부러 닫히지 않습니다. 이때 FMLE 창에 '게임 규칙을 원래대로 돌리지 못해서 FMLE를 열어 두었습니다'가 뜹니다. 안내대로 한 뒤 FMLE를 닫고 다시 설치합니다.

에리를 켜 두고 에리 설정의 FMLE 창을 닫아도 남기를 켰다면, FMLE는 창을 닫아도 알림 영역에 남아 있습니다. 에리를 오른쪽 클릭해 FMLE를 끝낸 뒤 다시 합니다.

그 밖의 문제는 문제가 생겼을 때를 봅니다.
