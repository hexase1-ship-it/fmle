# FMAX 설치 안내

FMAX(예전 이름 FMLE)는 Football Manager 27(FM27)을 켜 둔 채로 선수·구단·스태프 값을 바꾸는 편집기예요. 게임 파일은 고치지 않고, FMAX가 켜져 있는 동안 게임이 쓰는 값만 바꿔요.

- **필요한 것:** Windows 10 또는 11(64비트), FM27 **27.0.1+2494687**. 게임 판이 다르면 FMAX가 연결하지 않아요. Game Pass(Xbox 앱)판은 아직 지원하지 않아요.
- **먼저 세이브를 백업해 두세요.** 값을 바꾼 뒤 저장하면 세이브에 그대로 남아요.
- **사용법 위키:** 모든 화면의 쓰는 법을 실제 화면 그림과 함께 모아 두었어요. **https://hexase1-ship-it.github.io/fmle/**

## 설치하기

1. **https://getfmax.com** 에서 `FMAX-setup.exe`를 받아요. 작은 설치기라서, 실행할 때마다 가장 새 판을 받아 서명을 확인한 뒤 설치해요.
2. 받은 파일을 실행해요. 파란 창 **"Windows의 PC 보호"** 가 뜨면 **추가 정보 → 실행**을 눌러요.
   (이 창은 유료 인증서가 없는 프로그램이면 처음 한 번 떠요.)
3. 설치 화면에서 **다음 → 설치 → 마침**을 누르면 끝이에요. 시작 메뉴에 **FMAX**가 생기고, 마침 화면의 **"바탕화면 바로가기 만들기"** 를 켜 두면 바탕화면에도 생겨요.

관리자 권한은 필요 없어요. 내 계정에만 설치돼요. 예전 FMLE가 깔려 있으면 FMAX로 바꿔 깔고, 설정과 목록은 그대로 이어져요.

설치 폴더의 파일은 함께 두세요. `fmax.exe` 하나만 다른 폴더로 옮기거나 서로 다른 판의 파일을 섞으면 실행하지 않아요. 파일 확인 안내가 뜨면 `FMAX-setup.exe`로 다시 설치해 주세요. 설정과 목록을 남기려면 **"애플리케이션 데이터 삭제하기"** 는 체크하지 마세요.

## 새 판 받기

FMAX를 켰을 때 새 판이 있으면 창 위쪽에 **"새 판 … 이 나왔어요"** 가 뜨고, **설치**를 누르면 한 번 더 물어봐요.

- 받은 파일이 정말 FMAX 것인지 **FMAX 전용 도장(서명)** 으로 확인한 뒤에만 설치해요. 도장이 다르면 설치하지 않아요.
- 설치하기 전에 FMAX가 게임에 걸어 둔 편의 기능·규칙을 잠깐 풀고, 설치가 끝나면 FMAX가 다시 켜져요. 설정의 **"FMAX를 다시 켜면 지난번 상태 그대로"** 가 켜져 있으면 편의 기능·고정이 다시 켜져요.
- 남자팀 자격 유지를 쓰는 중이었다면, 다시 켠 뒤 세이브를 다시 불러오라는 안내가 뜰 수 있어요.
- **나중에**를 누르면 다음에 켤 때 다시 알려 줘요. `FMAX-setup.exe`를 다시 실행해도 똑같이 업데이트돼요. 설정과 목록은 그대로예요. 이때 중간에 뜨는 제거 화면의 **"애플리케이션 데이터 삭제하기"** 는 체크하지 마세요.

## 지우기

Windows **설정 → 앱 → 설치된 앱 → FMAX → 제거**를 눌러요.

- 지우기 전에 FMAX가 켜져 있으면 게임에 걸어 둔 것을 되돌리고 닫아요.
- **"애플리케이션 데이터 삭제하기"** 에 체크하면 FMAX 설정, 편의 기능·고정 목록, 즐겨찾기도 같이 지워져요. 체크하지 않으면 남아서 다시 설치할 때 그대로 돌아와요.

## 이럴 때는

- **"FMAX가 아직 닫히지 않았어요"** 가 뜨면: FMAX 창에 뜬 안내를 확인하고 FMAX를 닫은 뒤 다시 해요. FMAX는 게임에 건 코드를 되돌리지 못하면 일부러 닫히지 않아요.
- **게임에 연결이 안 되면:** FM27 판이 27.0.1+2494687인지 확인해요.
- 설치 파일은 **getfmax.com의 `FMAX-setup.exe`** 로만 받아요. 다른 곳에서 받은 파일은 업데이트 도장을 확인할 수 없어요.
